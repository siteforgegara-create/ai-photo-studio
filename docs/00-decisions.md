# 00 — Решения владельца (ред. 17.10.2026: премиальная headshot-концепция)

Этот документ приоритетнее любого макета. Если картинка ему противоречит, прав документ.

## Позиционирование
- **Премиальные AI-headshots, которые действительно похожи на человека.** Главный продукт — съёмка (shoot). Studio — место доработки кадров. Бесплатные инструменты — вход трафика.
- Ключевое обещание (формулировки в UI): **Headshots that actually look like you.** · **See free previews before you pay.** · **Every photo checked for likeness.** · **4K on every plan.** · **Edits included.**
- Целевая аудитория: англоязычные специалисты (LinkedIn, резюме, сайт, био спикера, агенты недвижимости, юристы, врачи, консультанты).

## Монетизация

| # | Тема | Решение |
|---|---|---|
| M1 | Модель | Разовая **съёмка** (пакет) + **кредиты** на правки в Studio. Подписок нет |
| M2 | Тарифы съёмки | **Essential $29** — 20 отобранных кадров, 2 стиля, 10 кредитов на правки · **Professional $49** ★ — 50 кадров, 5 стилей, 30 кредитов · **Executive $79** — 100 кадров, все стили, 80 кредитов, приоритетная очередь. На всех тарифах: 4K, коммерческая лицензия, фильтр сходства. Цены и объёмы — в `src/config/packs.ts`; окончательно утвердим после бенчмарка себестоимости |
| M3 | Докупка кредитов | Три пакета (20 / 60 / 150 кредитов), цены `TBD` в конфиге. Кредиты не сгорают |
| M4 | Цена правок | Background, Outfit, Retouch, Relight — **1 кредит за вариант**. Creative Style, Place Me Here — **2 кредита за вариант**. Crop & Export — бесплатно. Варианты 1/2/4, по умолчанию 2 |
| M5 | Бесплатное превью | **4 кадра 512px с водяным знаком**, один раз на аккаунт (подтверждённый email или Google) + лимит по IP/устройству на бэкенде. Заменяет стартовый бонус кредитами. Купить съёмку можно и без превью |
| M6 | Возвраты | Съёмка: **полный возврат до первого скачивания в полном размере** (одиночное или ZIP). Кредиты: неиспользованный пакет — в течение 14 дней. Неудачная или заблокированная правка — автоматический возврат кредитов |
| M7 | Подтверждение | Перед правкой: `Generate · N credits` + модалка с `Don't ask again`; если N > 6, модалка показывается всегда. Покупка — через checkout Lemon Squeezy (сейчас mock) |
| M8 | Баланс кредитов | Один общий баланс на аккаунт (`credit_ledger` по `user_id`). У съёмки своего счётчика нет. На странице съёмки и в Studio: `30 edit credits available` из баланса аккаунта |

## Продукт

| # | Тема | Решение |
|---|---|---|
| P1 | Селфи | **4–8 фото**, JPEG/PNG/WebP/HEIC до 15 MB (HEIC → JPEG в браузере), ресайз до 4096 px, удаление EXIF. Проверка качества **в браузере** до загрузки: ровно одно лицо, лицо достаточно крупное, резкость, освещённость, дубликаты. У каждого селфи — статус ✓ / ⚠ / ✕ с причиной. Нужно минимум 4 прошедших ✓ |
| P2 | Согласие | Обязательный чекбокс: `These photos are of me, or I have explicit permission from the adult pictured.` + ссылка на Terms |
| P3 | Предпочтения съёмки | Outfit: `Keep my outfit / Suit / Blazer / Smart casual / Let us choose`. Glasses: `Keep / Remove`. Стили — из каталога `styles.ts` (12 стилей), число по тарифу |
| P4 | Фильтр сходства | Каждый сгенерированный кадр сравнивается с селфи по сходству лица и проверяется на артефакты. Кадры ниже порога не показываются; генерация добирает кадры до обещанного числа. В UI обещаем «checked for likeness», **без процентов** |
| P5 | Studio | Редактор одного кадра из съёмки. Инструменты: Background, Outfit, Retouch, Relight, Creative Style (бывший Photoshoot), Place Me Here, Crop & Export. Правки сохраняются в съёмку как производные кадры |
| P6 | Демо | Гость и пользователь без съёмок видят Studio и Homepage на **демо-примерах** (подписаны `Example`), 0 запросов. Галочка `Show Demo Image` нужна только тому, у кого есть свои кадры |
| P7 | Free tools | `/tools/background-remover` и `/tools/photo-editor` — **без входа**, обработка полностью в браузере, файл не уходит на сервер. Под результатом — мягкий CTA `Want a studio-quality headshot? Get free previews →` |
| P8 | Хранение | Селфи удаляются через **24 часа** после завершения съёмки (или после превью, если покупки не было). Кадры съёмки и правки хранятся **30 дней** с момента готовности, на странице съёмки — таймер `Deletes on Nov 16`, кнопка `Delete now`; письмо-напоминание за 2 дня. Публичной галереи нет |
| P9 | Модерация | Согласие (P2); safety checker модели; блокировка → понятное сообщение + возврат; фильтр текстовых полей (Place Me Here, Creative Style); запреты в Terms (чужие фото без согласия, несовершеннолетние, NSFW, обман) |
| P10 | Teams | **После запуска.** Сейчас — лендинг `/teams` с формой ожидания (email, размер команды). Модель данных допускает владельца-команду |
| P11 | SEO | Страницы `/headshots/[useCase]` из конфига: linkedin, resume, real-estate-agents, lawyers, doctors, speakers, consultants (стартовый набор, расширяемый) |
| P12 | Бренд | «AI Photo Studio» — **рабочее** имя, только через `brand.ts` и `<Logo />`. Финальное имя и домен — до запуска |
| P13 | Время генерации | Не обещаем, пока нет бенчмарка. UI: `We'll email you when your headshots are ready — you can close this page.` |

## Отменённые решения прежней версии
Хаб из 7 равноправных инструментов; кредиты как единственная модель оплаты; стартовый бонус кредитами (заменён превью); «гость видит только демо» (free tools теперь открыты); хранение «24 ч + Save for Later» (заменено на P8); вкладки My Photos / Results в Studio (заменены на Shoot / Edits).
